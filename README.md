# Government vs Opposition – LLM Political Debate

Two free LLMs (via OpenRouter) debate the politics of a country you choose.
One plays the government, the other the opposition. Both must back arguments with data and statistics.
Built with Gradio. Max 10 rounds.

## Setup
```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env   # then put your OpenRouter key in .env
python app.py
```
Open http://127.0.0.1:7860
